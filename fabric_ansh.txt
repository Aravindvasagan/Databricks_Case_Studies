👉 Helps Spark read only relevant data

Query reads only needed partitions

Good:

int, date, decimal ✅

🔹 1. What is Semantic Model in Microsoft Fabric?
👉 A Semantic Model is a business-friendly layer on top of data used for reporting and analytics.
Previously called:
👉 Power BI Dataset

🔹 Why do we need Semantic Model?
Raw database tables are hard for business users.
Example raw table:
cust_id | ord_amt | txn_dt
Business users prefer:
Customer Name | Sales Amount | Order Date
👉 Semantic model makes data:


Easy to understand


Reusable


Optimized for reporting



🔹 What Semantic Model Contains
ComponentPurposeTablesBusiness dataRelationshipsConnect tablesMeasuresCalculations (SUM, AVG)HierarchiesDrill-downKPIsBusiness metrics

🔹 Example
Sales Table
customer_idamountdate
Measure:
Total Sales = SUM(Sales[amount])
👉 Business users use:


Total Sales


Monthly Sales


Profit KPI


without writing SQL.

🔹 How it Works
Lakehouse / Warehouse        ↓Semantic Model        ↓Power BI Reports

🔹 When to Use Semantic Model
✅ Reporting
✅ Self-service BI
✅ Business dashboards
✅ Centralized metrics

🔹 Benefits


Reusable calculations


Faster reporting


Security control


Business-friendly naming



🔹 2. What is Endorsement in Fabric?
👉 Endorsement = Trust label for data items
Used to tell users:
👉 “This dataset/report is trusted and approved.”

🔹 Types of Endorsement
TypeMeaningPromotedRecommendedCertifiedOfficially approved

🔹 1. Promoted
👉 Created by:


Analysts


Data teams


Means:
✅ “Good dataset to use”

🔹 2. Certified
👉 Approved by:


Governance/admin teams


Means:
✅ Official trusted enterprise data

🔹 Example
Sales Dashboard → Certified
Business users know:
👉 Data is reliable

🔹 Why Endorsement is Important
✅ Avoid duplicate reports
Everyone uses same trusted dataset

✅ Improve trust
Users know which reports are official

✅ Governance
Supports enterprise standards

🔹 Real Flow
Lakehouse   ↓Semantic Model   ↓Certified Dataset   ↓Power BI Reports
